## 四、安全验收

- API Key 不进入 Repository、Artifact、Memory 或 ToolCall。
- API Key 与数据库 URL 不进入 Settings `repr`。
- HTTP 日志不记录请求正文和 Header。
- Terminal 只接受白名单 Runner。
- File Tool 使用 Workspace 边界和受保护路径策略。
- Git Commit 受 Review、Test 和文件哈希三重门禁。
- Docker App 使用非 root、只读根文件系统、Capability Drop 和 No New Privileges。
- Project/Memory/RAG 检索具备项目作用域隔离。

## 五、工程亮点

1. Artifact-driven：Agent 之间传递可验证 Pydantic Artifact，而不是不可控聊天文本。
2. Governed Tool Calling：Agent 的能力由权限和上下文授予，所有执行都有审计记录。
3. Durable Workflow：任务状态、Checkpoint、Execution 和 Event 均持久化。
4. Evidence Traceability：每个产物可以追踪需求、工具、代码上下文和 Memory 引用。
5. Failure-aware：Review/Test 失败会返工，并具有最大次数和明确终态。
6. Production-minded：具备迁移、日志、指标、健康检查、容器和冒烟验证。

## 六、未完成边界
