# 代码 RAG 检索评测基线

## 评测目标

当前评测用于防止索引、Tokenization、BM25、向量排序或融合逻辑在重构后退化。它不是公开 Benchmark，也不能证明系统已经具备生产级代码语义检索能力。

## 指标

- `Recall@K`：前 K 个结果中是否至少存在一个相关文件和符号。
- `MRR`：第一个相关结果排名的倒数均值。

## 当前确定性用例

测试仓库包含认证和计费两个模块：

| Query | 相关文件 | 相关符号 |
|---|---|---|
| authentication token validation | `auth.py` | `validate_token` |
| calculate invoice total | `billing.py` | `calculate_invoice` |

当前自动化门禁要求：

- `Recall@3 = 1.0`
- `MRR = 1.0`

## 局限

当前数据集规模很小，且查询与源码存在较明显的词法重叠。接入真实 Embedding 后，需要增加同义表达、跨文件调用、配置定位、错误日志定位和多语言项目用例，并将评测数据与实现代码分离。
